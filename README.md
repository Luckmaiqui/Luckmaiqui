## Projeto principal

### [Pacote de Atualizações do JasperStudio](https://github.com/Luckmaiqui/pacote-de-atualizacoes-do-jasperstudio)

Complementos independentes para o Jaspersoft Studio Community 6.20.6 no Windows:

- Temas com cores personalizáveis.
- Tradução para Português (Brasil).
- Ferramentas de pesquisa e ordenação de conexões.
- Instaladores separados por componente.

## Tecnologias presentes nos projetos

HTML · CSS · C# · PowerShell · Node.js · Java
